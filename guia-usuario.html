Normalizador de Contratos DMS

Andreani · Guía de Usuario

Una herramienta simple para validar y normalizar contratos DMS

🤔 ¿Qué hace esta herramienta?

Esta herramienta está diseñada para automatizar y simplificar el proceso de preparación de contratos DMS para la plataforma Andreani.

¿Qué problema resuelve? El archivo Excel que recibes tiene información desordenada, fórmulas que deben convertirse a valores estáticos, y datos que necesitan ser validados y normalizados antes de ser procesados por el sistema.

¿Qué hace exactamente?

  • ✅ Valida que los campos del formulario sean correctos
  • 🔄 Convierte todas las fórmulas a valores estáticos
  • 🗑️ Elimina la hoja Formulario (solo se usa para la carga)
  • 📑 Organiza la hoja Referencias al final
  • 🏢 Limpia las direcciones vacías
  • 📝 Renombra el archivo con los datos del contrato
  • 💬 Genera un mensaje listo para copiar
  • 📥 Descarga una plantilla simplificada para completar los datos

📋 Reglas de validación y normalización

La herramienta verifica automáticamente que los datos ingresados sean correctos y normaliza aquellos valores que tengan errores comunes de tipeo, acentuación o mayúsculas/minúsculas.

📌 Código de Contrato (C3)
✅ 9 dígitos
Ej: 351005959
📌 Sociedad SAP (C7)
✅ Debe ser "1100"
Para B2B siempre es 1100
📌 Habilitado (C8)
✅ 1 o 0
1 = Activo, 0 = Inactivo
📌 Campos booleanos
✅ true/false, 1/0, si/no
AllowRescue, ObligatoryGauge, etc.
📌 Normalización automática por diccionario de sinónimos
La herramienta corrige automáticamente errores comunes de tipeo en los siguientes campos:
  • Tipo de Envío: "paqueteria" → "Paquetería"
  • Tipo de Envío: "logistica inversa" → "Logística inversa"
  • ¿Usa remito?: "con remito" → "CON_REMITO"
  • ¿Usa remito?: "sin remito" → "SIN_REMITO"
  • Logística Solicitada, Continente, SLA, Formulario Mobile: normaliza mayúsculas, minúsculas y acentos
📌 ¿Usa remito? (HasDeliveryNote) — Normalización automática:
true / 1 / si → CON_REMITO
false / 0 / no → SIN_REMITO
con remito / CON_REMITO / ConRemito → CON_REMITO
sin remito / SIN_REMITO / SinRemito → SIN_REMITO
digitalizado / DIGITALIZADO / Digitalizado → DIGITALIZADO
📌 Valores válidos del campo SLA
El campo SLA acepta únicamente estos valores exactos:
  • SLA 1
  • SLA 2
  • SLA 3
  • SLA 4 - Logistica Asegurada V2
  • SLA PALLETS
  • SLA BIGGER
💡 Nota: SLA 1, 2 y 3 se usan en formato corto (no "SLA 1 - Estándar B2B"). El SLA 4 mantiene su descripción completa.
🔗 Validación cruzada automática (bidireccional)
La herramienta corrige automáticamente combinaciones inválidas entre ciertos campos. Si uno de los campos se completa, el otro se ajusta automáticamente:
  • Tipo de Envío = "Logística Asegurada" ↔ SLA = "SLA 4 - Logistica Asegurada V2"
  • Continente = "Pallets" ↔ SLA = "SLA PALLETS"
  • Continente = "Bultos Bigger" ↔ SLA = "SLA BIGGER"
💡 Ejemplo: Si seleccionás Tipo de Envío = "Logística Asegurada" pero el SLA es "SLA 1", la herramienta auto-corrige el SLA a "SLA 4 - Logistica Asegurada V2" e informa en el log.
🔢 Normalización de Código del Cliente

El campo Código del Cliente (CodigoSolicitanteERP) (C5) puede llegar en diferentes formatos. La herramienta lo normaliza automáticamente:

✅ Válido
6 dígitos
Ej: 123456
🔄 Normalizado
10 dígitos con 4 ceros
0000120761 → 120761
❌ Inválido
10 dígitos sin 4 ceros
1234567890 → ❌ Error
❌ Inválido
Menos de 6 o más de 10
12345 o 12345678901 → ❌ Error
🏢 Limpieza de direcciones

Si el ejecutivo solo completó algunas direcciones, la herramienta elimina automáticamente las filas vacías de la hoja Direcciones.

📋 Ejemplo:
ANTES Street | City | AddressType Amado Aufranc | ESPERANZA | 1 0 | 0 | 2 ← vacía 0 | 0 | 3 ← vacía Amado Aufranc | ESPERANZA | 7 0 | 0 | 8 ← vacía
⬇️
DESPUÉS Street | City | AddressType Amado Aufranc | ESPERANZA | 1 ← se conserva Amado Aufranc | ESPERANZA | 7 ← se conserva
✅ Solo se conservan las filas que tienen al menos un campo con información real
📝 Nombre de archivo personalizado

La herramienta renombra automáticamente el archivo de salida con los datos del contrato:

Alta de contrato DMS 351005959 120761 NOISACO SA.xlsx
  • Alta de contrato DMS → Texto fijo
  • 351005959 → Código de Contrato (C3) — Obligatorio
  • 120761 → Código del Cliente (C5) — Obligatorio
  • NOISACO SA → Razón Social (C14) — Opcional

📖 Normalización por diccionario de sinónimos

La herramienta incluye un diccionario de sinónimos que permite corregir automáticamente errores comunes de tipeo en los campos con valores predefinidos.

¿Cómo funciona?

  • 🔍 Detección: Identifica valores que no coinciden exactamente con los valores válidos
  • 🔄 Corrección: Busca en el diccionario de sinónimos y aplica la corrección automática
  • 📝 Registro: Todas las correcciones se registran en el log para trazabilidad
  • ❌ Error: Si el valor no se reconoce, muestra un error con la lista de valores válidos
📋 Ejemplos de normalización:
Campo: Tipo de Envío ❌ "paqueteria" → ✅ "Paquetería" ❌ "logistica inversa" → ✅ "Logística inversa" ❌ "cadena de frio" → ✅ "Cadena de frío" ❌ "retira deposito" → ✅ "Retira depósito" Campo: ¿Usa remito? ❌ "con remito" → ✅ "CON_REMITO" ❌ "sin remito" → ✅ "SIN_REMITO" ❌ "CONREMITO" → ✅ "CON_REMITO" ❌ "digitalizado" → ✅ "DIGITALIZADO" Campo: Continente ❌ "pallet" → ✅ "Pallets" ❌ "pallets" → ✅ "Pallets" ❌ "bigger" → ✅ "Bultos Bigger" ❌ "bulto bigger" → ✅ "Bultos Bigger" Campo: SLA ❌ "sla1" → ✅ "SLA 1" ❌ "sla 2" → ✅ "SLA 2" ❌ "sla3" → ✅ "SLA 3" ❌ "sla pallet" → ✅ "SLA PALLETS" ❌ "sla bigger" → ✅ "SLA BIGGER" ❌ "logistica asegurada v2" → ✅ "SLA 4 - Logistica Asegurada V2"
💡 Beneficios:
✅ Reduce errores por tipeo manual
✅ Acepta valores sin acentos o con mayúsculas/minúsculas incorrectas
✅ Mejora la experiencia del usuario
✅ Mantiene la trazabilidad con logs de normalización

📥 Plantilla de Contrato

La herramienta incluye una plantilla simplificada para que completes los datos de tu contrato. ¿Para qué sirve? Si no tenés un archivo Excel preparado, podés descargar esta plantilla, completarla y luego arrastrarla a la herramienta.

📋 Características de la plantilla:
  • ✅ Etiquetas amigables: Los campos tienen nombres comerciales fáciles de entender
  • ✅ Ayuda integrada: Cada campo incluye una descripción y ejemplos
  • ✅ Celdas bloqueadas: Los campos que no deben modificarse están en color gris
  • ✅ Valores por defecto: Campos como "Sociedad SAP" y "Habilitado" ya vienen precargados
  • ✅ Instrucciones claras: Al descargar, un modal te guía paso a paso

¿Cómo obtenerla?

1️⃣ Hacé clic en "📥 Descargar plantilla" en la pantalla principal
→
2️⃣ Completá los datos en el Excel
→
3️⃣ Arrastrá el archivo a la herramienta
📌 Estructura de la plantilla:
📋 Hoja: Formulario 🔑 DATOS DEL CONTRATO • Código de Contrato: 9 dígitos, ej: 351005959 • Código del Cliente: 6 dígitos, ej: 125383 📦 DATOS DEL ENVÍO • Tipo de Envío: Minorista, Mayorista, Logística Asegurada, etc. • Condición de Entrega: Texto libre • Modalidad de Entrega: Domicilio, Sucursal, etc. 🏢 DATOS DEL CLIENTE • Razón Social: Nombre completo del cliente ⚙️ CONFIGURACIÓN • Nivel de Servicio (SLA): SLA 1, SLA 2, SLA 3, SLA 4 - Logistica Asegurada V2, SLA PALLETS, SLA BIGGER • ¿Usa remito?: CON_REMITO, SIN_REMITO, DIGITALIZADO • Campos booleanos: true / false 📋 NIVELES DE ESFUERZO • Logística Solicitada: Entrega, Logística inversa, etc. • Continente: Contenedor, Pallets, Bultos Bigger, Sobre, etc. • Plazo: SLA 1, SLA 2, SLA 3, SLA 4, SLA PALLETS, SLA BIGGER • Formulario Mobile B2B: Formulario B2B 1 al 13 📍 DIRECCIONES (obligatorias: Devolución y Devolución de Remitos)
